# CSS Partial File Map

`assets/css/app.css` imports these files in order:

1. `00-foundation.css` for resets, variables, map chrome, and global UI affordances.
2. `10-panel.css` for the bottom panel and its internal controls.
3. `20-overlays.css` for setup, mode selection, and modal overlays.

The numbering is intentional and preserves the original cascade.
